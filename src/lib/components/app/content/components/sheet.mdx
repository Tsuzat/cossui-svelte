## Usage

```svelte
<script lang="ts">
  import {
    Sheet,
    SheetClose,
    SheetDescription,
    SheetFooter,
    SheetHeader,
    SheetPanel,
    SheetPopup,
    SheetTitle,
    SheetTrigger
  } from '#lib/components/ui/sheet';
</script>

<Sheet>
  <SheetTrigger>Open</SheetTrigger>
  <SheetPopup>
    <SheetHeader>
      <SheetTitle>Are you absolutely sure?</SheetTitle>
      <SheetDescription>
        This action cannot be undone. This will permanently delete your account and remove your
        data from our servers.
      </SheetDescription>
    </SheetHeader>
    <SheetPanel>Content</SheetPanel>
    <SheetFooter>
      <SheetClose>Close</SheetClose>
    </SheetFooter>
  </SheetPopup>
</Sheet>
```

## API Reference

### Sheet

Root component. Wrapper for `Dialog.Root` from ShardsUI. `open` is bindable (`bind:open`); `onOpenChange` and the other root props are forwarded.

### SheetTrigger

Trigger button that opens the sheet. Wrapper for `Dialog.Trigger` from ShardsUI. Use the `child` snippet to render a custom element.

### SheetPopup

Popup container that displays the sheet content, including the backdrop and viewport. Also exported as `SheetContent`.

| Prop              | Type                                      | Default     | Description                                      |
| ----------------- | ----------------------------------------- | ----------- | ------------------------------------------------ |
| `side`            | `"right" \| "left" \| "top" \| "bottom"`  | `"right"`   | Controls which side of the screen the sheet opens from |
| `variant`         | `"default" \| "inset"`                    | `"default"` | Controls the sheet style. `inset` adds spacing around the sheet on desktop screens |
| `showCloseButton` | `boolean`                                 | `true`      | When true, displays a close button in the top-right corner |
| `closeProps`      | `Dialog.Close` props                      | -           | Props forwarded to the internal close button, useful for overriding `aria-label` |
| `portalProps`     | `Dialog.Portal` props                     | -           | Props forwarded to the internal portal (`keepMounted`, `container`, etc.) |

**Example:**

```svelte
<!-- Right side sheet (default) -->
<SheetPopup side="right">...</SheetPopup>

<!-- Left side sheet -->
<SheetPopup side="left">...</SheetPopup>

<!-- Sheet with inset variant -->
<SheetPopup side="right" variant="inset">...</SheetPopup>
```

### SheetHeader

Container for the sheet title and description. Renders a `div` and accepts standard div attributes.

### SheetFooter

Footer section for action buttons. Renders a `div`.

| Prop        | Type                     | Default     | Description                                      |
| ----------- | ------------------------ | ----------- | ------------------------------------------------ |
| `variant`   | `"default" \| "bare"`    | `"default"` | Controls the footer styling. `default` includes border and background, `bare` removes them |

### SheetTitle

Title component. Wrapper for `Dialog.Title` from ShardsUI.

### SheetDescription

Description component. Wrapper for `Dialog.Description` from ShardsUI.

### SheetPanel

Scrollable content container. Automatically wraps content in a `ScrollArea` component. Renders a `div`.

| Prop         | Type      | Default | Description                                      |
| ------------ | --------- | ------- | ------------------------------------------------ |
| `scrollFade` | `boolean` | `true`  | When true, shows a fade effect at scroll edges   |

**Example:**

```svelte
<SheetPanel>
  <!-- Long content that will scroll if it exceeds the sheet height -->
  <div>...</div>
</SheetPanel>
```

### SheetClose

Close button component. Wrapper for `Dialog.Close` from ShardsUI.

### SheetPortal

Portal component for rendering outside the DOM hierarchy. Alias for `Dialog.Portal` from ShardsUI.

### SheetBackdrop

Backdrop/overlay component. Also exported as `SheetOverlay`. Wrapper for `Dialog.Backdrop` from ShardsUI.

### SheetViewport

Positions the popup on the chosen `side`; rendered by `SheetPopup`.
