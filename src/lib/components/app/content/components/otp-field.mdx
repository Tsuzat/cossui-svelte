## Usage

```svelte
<script lang="ts">
  import { OTPField, OTPFieldInput, OTPFieldSeparator } from '#lib/components/ui/otp-field';

  let value = $state('');
</script>

<OTPField aria-label="Verification code" maxlength={6} bind:value>
  {#snippet children({ cells })}
    {#each cells.slice(0, 3) as cell, i (i)}
      <OTPFieldInput aria-label={`Character ${i + 1} of 6`} {cell} />
    {/each}
    <OTPFieldSeparator />
    {#each cells.slice(3) as cell, i (i)}
      <OTPFieldInput aria-label={`Character ${i + 4} of 6`} {cell} />
    {/each}
  {/snippet}
</OTPField>
```

## API Reference

A custom Svelte component built on a single hidden input (not a ShardsUI wrapper). The `OTPField` `children` snippet receives `{ cells, isFocused, isHovering }`; render one `OTPFieldInput` per cell and pass it the `cell`.

### OTPField

Root component. Accepts standard input attributes; `class` is merged with the default layout styles.

| Prop            | Type                                | Default         | Description                          |
| --------------- | ----------------------------------- | --------------- | ------------------------------------ |
| `maxlength`     | `number`                            | `6`             | Number of characters (cells)         |
| `value`         | `string`                            | `""`            | Current value (bindable)             |
| `onValueChange` | `(value: string) => void`           | -               | Called when the value changes        |
| `onComplete`    | `(value: string) => void`           | -               | Called when all cells are filled     |
| `size`          | `"default" \| "lg"`                 | `"default"`     | Size applied to all slots            |
| `pattern`       | `string \| RegExp`                  | -               | Restricts accepted characters (for example `^[0-3]+$`) |
| `inputmode`     | `string`                            | `"numeric"`     | Virtual keyboard hint                |
| `disabled`      | `boolean`                           | `false`         | Disables the field                   |
| `pasteTransformer` | `(text: string) => string`       | -               | Sanitizes pasted text before it is inserted |

### OTPFieldInput

Renders one OTP character cell.

| Prop          | Type      | Description                                      |
| ------------- | --------- | ------------------------------------------------ |
| `cell`        | `PinInputCell` | The cell from the `children` snippet (required) |
| `class`       | `string`  | Merged with the default slot styles              |
| `placeholder` | `string`  | Shown in empty slots                             |
| `mask`        | `boolean` | When `true`, masks the entered character         |

Label the OTP control on `OTPField` with `aria-label` or a visible `Label`, and give each slot an `aria-label` such as `Character 2 of 6`.

### OTPFieldSeparator

Visual separator between slot groups. Styled wrapper for `Separator` from ShardsUI.
