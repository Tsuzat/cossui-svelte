## Usage

```svelte
<script lang="ts">
  import {
    Select,
    SelectGroup,
    SelectGroupLabel,
    SelectItem,
    SelectPopup,
    SelectTrigger
  } from '#lib/components/ui/select';

  const items = [
    { label: 'Next.js', value: 'next' },
    { label: 'Vite', value: 'vite' },
    { label: 'Astro', value: 'astro' }
  ];

  let value = $state('next');
  const selectedLabel = $derived(items.find((i) => i.value === value)?.label);
</script>

<Select bind:value {items}>
  <SelectTrigger aria-label="Select framework">
    <span class="flex-1 truncate">{selectedLabel}</span>
  </SelectTrigger>
  <SelectPopup>
    {#each items as item (item.value)}
      <SelectItem value={item.value}>{item.label}</SelectItem>
    {/each}
  </SelectPopup>
</Select>
```

## API Reference

### Select

Root component. Wrapper for `Select.Root` from ShardsUI. `value` is bindable (`bind:value`, a string, or a string array with `multiple`); `items` and the remaining root props (`onValueChange`, `disabled`, `name`, etc.) are forwarded.

### SelectTrigger

Trigger button that opens the select dropdown, with a built-in chevron icon. Styled wrapper for `Select.Trigger` from ShardsUI. Render the current label as its children.

| Prop   | Type                        | Default     | Description                                      |
| ------ | --------------------------- | ----------- | ------------------------------------------------ |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Controls the size of the trigger                 |

### SelectPopup

Popup container for select options. Also exported as `SelectContent`.

| Prop          | Type                                     | Default    | Description                                      |
| ------------- | ---------------------------------------- | ---------- | ------------------------------------------------ |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` | Side of the trigger to position the popup        |
| `align`       | `"start" \| "center" \| "end"`           | `"center"` | Alignment relative to the trigger                |
| `sideOffset`  | `number`                                 | `4`        | Distance from the trigger in pixels              |
| `alignOffset` | `number`                                 | `0`        | Offset along the alignment axis                  |
| `anchor`      | `Element`                                | -          | Positions the popup against this element instead of the trigger |
| `portalProps` | `Select.Portal` props                    | -          | Props forwarded to the internal portal (`keepMounted`, `container`, etc.) |

### SelectItem

Individual select option with a built-in check indicator. Styled wrapper for `Select.Item` from ShardsUI. Takes a `value`; the visible text comes from the `label` prop, the children snippet (which receives `{ highlighted, selected }`), or falls back to `String(value)`.

### SelectGroup

Groups related select items. Wrapper for `Select.Group` from ShardsUI.

### SelectLabel

Label for all options in the popup. Styled wrapper for `Select.Label` from ShardsUI. Clicking it focuses the select trigger without opening the popup.

### SelectGroupLabel

Label for a select group. Styled wrapper for `Select.GroupLabel` from ShardsUI.

### SelectSeparator

Visual separator between items. Styled wrapper for `Select.Separator` from ShardsUI.

### SelectScrollUpButton / SelectScrollDownButton

Scroll arrows rendered automatically by `SelectPopup`.

### SelectButton

A standalone `<button>` styled like a `SelectTrigger`, with a chevron icon. Takes the same `size` prop (`"sm" | "default" | "lg"`, default `"default"`) and renders its children as the label.

### selectTriggerVariants

The `tv` recipe behind `SelectTrigger` and `SelectButton`. Apply it as a `class` on other triggers (e.g. `ComboboxTrigger`) to give them select-like appearance.

```svelte
<script lang="ts">
  import { ComboboxTrigger, ComboboxValue } from '#lib/components/ui/combobox';
  import { selectTriggerVariants } from '#lib/components/ui/select';
</script>

<ComboboxTrigger class={selectTriggerVariants()}>
  <ComboboxValue placeholder="Select a fruit" />
</ComboboxTrigger>
```
