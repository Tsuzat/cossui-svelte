## Usage

```svelte
<script lang="ts">
  import {
    Popover,
    PopoverClose,
    PopoverDescription,
    PopoverPopup,
    PopoverTitle,
    PopoverTrigger
  } from '#lib/components/ui/popover';
</script>

<Popover>
  <PopoverTrigger>Open Popover</PopoverTrigger>
  <PopoverPopup>
    <PopoverTitle>Popover Title</PopoverTitle>
    <PopoverDescription>Popover Description</PopoverDescription>
    <PopoverClose>Close</PopoverClose>
  </PopoverPopup>
</Popover>
```

## API Reference

### Popover

Root component. Wrapper for `Popover.Root` from ShardsUI. `open` is bindable (`bind:open`); `onOpenChange` and the other root props are forwarded.

### PopoverTrigger

Trigger button that opens the popover. Wrapper for `Popover.Trigger` from ShardsUI. Style it with `class` (for example `class={buttonVariants({ variant: 'outline' })}`) and change the rendered tag with `as`; ShardsUI parts have no `child` snippet or render prop, so don't nest a `Button` inside it.

### PopoverPopup

Popup container that displays the popover content. Also exported as `PopoverContent`.

| Prop           | Type                                     | Default    | Description                                      |
| -------------- | ---------------------------------------- | ---------- | ------------------------------------------------ |
| `tooltipStyle` | `boolean`                                | `false`    | When true, applies tooltip-like styling (smaller padding) |
| `showArrow`    | `boolean`                                | `false`    | Renders an arrow pointing at the anchor          |
| `side`         | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` | Side of the trigger to position the popup        |
| `align`        | `"start" \| "center" \| "end"`           | `"center"` | Alignment relative to the trigger                |
| `sideOffset`   | `number`                                 | `4`        | Distance from the trigger in pixels              |
| `alignOffset`  | `number`                                 | `0`        | Offset along the alignment axis                  |
| `customAnchor` | `Element`                                | -          | Positions the popup against this element instead of the trigger |
| `portalProps`  | `Popover.Portal` props                   | -          | Props forwarded to the internal portal (`keepMounted`, `container`, etc.) |

### PopoverTitle

Title text for the popover. Styled wrapper for `Popover.Title` from ShardsUI.

### PopoverDescription

Description text for the popover. Styled wrapper for `Popover.Description` from ShardsUI.

### PopoverClose

Close button for the popover. Wrapper for `Popover.Close` from ShardsUI.

### PopoverHandle

Re-export of `Popover.Handle` from ShardsUI, for detached popover triggers.
