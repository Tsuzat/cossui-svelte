## Usage

```svelte
<script lang="ts">
  import { Slider, SliderValue } from '#lib/components/ui/slider';

  let value = $state(50);
</script>

<Slider bind:value getAriaLabel={() => 'Volume'} />
```

## API Reference

### Slider

Root component. Styled wrapper for `Slider.Root` from ShardsUI that renders the control, track, indicator and thumbs for you. `value` is bindable (a number, or an array of numbers for a range slider). `min`, `max`, `step`, `disabled`, `onValueChange` and the other root props are forwarded.

| Prop                     | Type                              | Default        | Description                                      |
| ------------------------ | --------------------------------- | -------------- | ------------------------------------------------ |
| `orientation`            | `"horizontal" \| "vertical"`      | `"horizontal"` | Slider orientation                               |
| `thumbCollisionBehavior` | `"push" \| "swap" \| "none"`      | `"push"`       | How adjacent thumbs behave when dragged into each other |
| `showTooltip`            | `boolean`                         | `false`        | Shows a tooltip with the value above each thumb while dragging |
| `tooltipContent`         | `(value: number) => number \| string` | -         | Formats the tooltip text                         |
| `getAriaLabel`           | `(index: number) => string`       | -              | Accessible name for each generated thumb         |

Note: The component sets `thumbAlignment="edge"`, which aligns thumbs to the edge of the track rather than centering them.

### SliderValue

Displays the current value. Styled wrapper for `Slider.Value` from ShardsUI.

## Examples

For accessible labelling and validation, prefer using the `Field` component with an associated `FieldLabel`. See the related example: [Slider field](/docs/field#slider-field).

Use `getAriaLabel` when there is no associated label. Name each range endpoint separately:

```svelte
<Slider
  value={[20, 80]}
  getAriaLabel={(index) => (index === 0 ? 'Minimum price' : 'Maximum price')}
/>
```

An associated `FieldLabel` continues to work without this prop. Setting `aria-label` on the root alone does not name its thumbs.
