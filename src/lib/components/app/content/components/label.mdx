```svelte
</script>

<Label for="email">Email</Label>
```

## API Reference

### Label

A plain styled `<label>` element. It accepts `class`, `bind:ref`, children and all standard label attributes (such as `for`).

## Examples

For accessible labelling and validation, prefer using the `FieldLabel` component. See some [related examples](/docs/field).
