## Usage

```svelte
<script lang="ts">
  import {
    Accordion,
    AccordionItem,
    AccordionPanel,
    AccordionTrigger
  } from '$lib/components/ui/accordion';
</script>

<Accordion>
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionPanel>Yes. It adheres to the WAI-ARIA design pattern.</AccordionPanel>
  </AccordionItem>
</Accordion>
```

## API Reference

### Accordion

Root component. Wraps `Accordion.Root` from ShardsUI.

| Prop       | Type                 | Default | Description                                                                 |
| ---------- | -------------------- | ------- | --------------------------------------------------------------------------- |
| `value`    | `string \| string[]` | -       | Open item value(s). Bindable with `bind:value` (array when `multiple`)      |
| `multiple` | `boolean`            | `false` | Allow several items to be open at once                                      |
| `disabled` | `boolean`            | `false` | Disable all items                                                           |

### AccordionItem

Individual accordion item container. Styled wrapper for `Accordion.Item` from ShardsUI with bottom border styling. Takes a `value` prop.

### AccordionTrigger

Trigger button that toggles the accordion panel. Styled wrapper for `Accordion.Trigger` from ShardsUI, rendered inside an `Accordion.Header`. Includes a built-in chevron icon that rotates when expanded.

### AccordionPanel

Collapsible content panel. Styled wrapper for `Accordion.Panel` from ShardsUI with animated height transitions. Also exported as `AccordionContent`.
