## Usage

```svelte
<script lang="ts">
  import { ToggleGroup, ToggleGroupItem } from '#lib/components/ui/toggle-group';

  let value = $state(['bold']);
</script>

<ToggleGroup bind:value>
  <ToggleGroupItem value="bold">Bold</ToggleGroupItem>
  <ToggleGroupItem value="italic">Italic</ToggleGroupItem>
  <ToggleGroupItem value="underline">Underline</ToggleGroupItem>
</ToggleGroup>
```

## API Reference

### ToggleGroup

Root component. Styled wrapper for `ToggleGroup` from ShardsUI. `value` (an array of pressed item values) is bindable. Provides shared variant and size to child toggles via context.

| Prop          | Type                         | Default        | Description                                |
| ------------- | ---------------------------- | -------------- | ------------------------------------------ |
| `variant`     | `"default" \| "outline"`     | `"default"`    | Controls the styling of all child toggles  |
| `size`        | `"default" \| "sm" \| "lg"`  | `"default"`    | Controls the size of all child toggles     |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout direction of the group              |
| `multiple`    | `boolean`                    | `false`        | Allow more than one item to be pressed     |

### ToggleGroupItem

Individual toggle button within the group. Styled wrapper for `Toggle` from ShardsUI. Takes a `value` and inherits variant and size from the parent `ToggleGroup` context.

### ToggleGroupSeparator

Visual separator between toggle buttons.
