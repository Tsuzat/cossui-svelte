## API Reference

### Input

Styled wrapper for `Input` from ShardsUI with custom size options. Supports `bind:value` and `bind:ref`, and forwards other props to the underlying input. The unstyled primitive is also exported as `InputPrimitive`.

| Prop       | Type                                  | Default     | Description                                      |
| ---------- | ------------------------------------- | ----------- | ------------------------------------------------ |
| `size`     | `"sm" \| "default" \| "lg" \| number` | `"default"` | Controls the input height. Number values are passed to the native `size` attribute |
| `unstyled` | `boolean`                             | `false`     | When true, removes the wrapper styling (border, shadow, etc.) |
