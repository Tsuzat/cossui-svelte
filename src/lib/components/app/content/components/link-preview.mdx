## Usage

```svelte
<script lang="ts">
  import {
    LinkPreviewCard,
    LinkPreviewContent,
    LinkPreviewTrigger
  } from '#lib/components/ui/link-preview';
</script>

<LinkPreviewCard>
  <LinkPreviewTrigger href="https://svelte.dev">@svelte</LinkPreviewTrigger>
  <LinkPreviewContent>The Svelte Framework.</LinkPreviewContent>
</LinkPreviewCard>
```

## API Reference

A thin wrapper over [Preview Card](/docs/preview-card).

### LinkPreviewCard

Root. Same props as `PreviewCard` (`open` is bindable).

### LinkPreviewTrigger

The link that opens the preview. Accepts `delay` and `closeDelay`.

### LinkPreviewContent

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `'top' | 'right' | 'bottom' | 'left'` | `bottom` |
| `align` | `'start' | 'center' | 'end'` | `center` |
| `sideOffset` | `number` | `4` |
| `alignOffset` | `number` |  |
| `showArrow` | `boolean` | `false` |
| `portalProps` | `PortalProps` |  |
