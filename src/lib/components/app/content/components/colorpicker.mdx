## Usage

```svelte
<script lang="ts">
  import { ColorPicker } from '#lib/components/ui/colorpicker';

  let color = $state('#4f46e5');
</script>

<ColorPicker bind:color />
```

## API Reference

Built on [Huey](https://github.com/hueycolor/huey) (`@hueycolor/svelte`) and the [Popover](/docs/popover) component.

### ColorPicker

| Prop | Type | Default |
| --- | --- | --- |
| `color` | `string | HueyColor` |  |
| `swatches` | `string[]` |  |
| `showSaturationArea` | `boolean` | `true` |
| `showInputs` | `boolean` | `true` |
| `showColorDropper` | `boolean` | `true` |
| `showColorSliders` | `boolean` | `true` |
| `swatchesEditable` | `boolean` | `true` |

`color` and `swatches` are bindable.
