## API Reference

### Spinner

An animated Lucide `LoaderCircle` icon with `role="status"` and `aria-label="Loading"`. Accepts the Lucide icon props (`size`, `class`, etc.).

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` |         |
