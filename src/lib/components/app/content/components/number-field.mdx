## Usage

```svelte
<script lang="ts">
  import {
    NumberField,
    NumberFieldDecrement,
    NumberFieldGroup,
    NumberFieldIncrement,
    NumberFieldInput,
    NumberFieldScrubArea
  } from '#lib/components/ui/number-field';

  let value = $state(0);
</script>

<NumberField bind:value>
  <NumberFieldScrubArea label="Quantity" />
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>
```

## API Reference

A custom Svelte component (not a ShardsUI wrapper). State is shared with the parts through context.

### NumberField

Root component.

| Prop       | Type                        | Default     | Description                                      |
| ---------- | --------------------------- | ----------- | ------------------------------------------------ |
| `value`    | `number`                    | -           | Current value (bindable)                         |
| `min`      | `number`                    | -           | Minimum value                                    |
| `max`      | `number`                    | -           | Maximum value                                    |
| `step`     | `number`                    | `1`         | Amount to change per increment, decrement or scrub unit |
| `disabled` | `boolean`                   | `false`     | Disables the field                               |
| `id`       | `string`                    | generated   | Id applied to the input                          |
| `size`     | `"sm" \| "default" \| "lg"` | `"default"` | Controls the size of all child components        |

### NumberFieldGroup

Container for the input and buttons.

### NumberFieldInput

Input element for the number value. Supports ArrowUp/ArrowDown, PageUp/PageDown (10 steps), Home and End.

| Prop     | Type                                   | Description                                      |
| -------- | -------------------------------------- | ------------------------------------------------ |
| `format` | `(value: number) => string`            | Formats the value for display while the input is not focused |
| `parse`  | `(display: string) => number \| undefined` | Parses the edited text back to a number (defaults to `parseFloat`) |

### NumberFieldIncrement

Button to increment the value. Renders a plus icon by default; pass children to replace it. Press and hold to repeat.

### NumberFieldDecrement

Button to decrement the value. Renders a minus icon by default; pass children to replace it. Press and hold to repeat.

### NumberFieldScrubArea

Draggable area for scrubbing the value. Must be used inside `NumberField`.

| Prop    | Type     | Default | Description                                      |
| ------- | -------- | ------- | ------------------------------------------------ |
| `label` | `string` | -       | Label text displayed in the scrub area           |

### NumberFieldValue

Displays the current value. Pass a `children` snippet, which receives `{ value }`, to customize rendering.
