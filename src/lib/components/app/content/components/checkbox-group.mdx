## Usage

```svelte
<script lang="ts">
  import { Checkbox } from '$lib/components/ui/checkbox';
  import { CheckboxGroup } from '$lib/components/ui/checkbox-group';
  import { Label } from '$lib/components/ui/label';

  let value = $state(['next']);
</script>

<CheckboxGroup aria-label="Select frameworks" bind:value>
  <Label>
    <Checkbox value="next" />
    Next.js
  </Label>
  <Label>
    <Checkbox value="vite" />
    Vite
  </Label>
  <Label>
    <Checkbox value="astro" />
    Astro
  </Label>
</CheckboxGroup>
```

## API Reference

### CheckboxGroup

Styled wrapper for `CheckboxGroup` from ShardsUI. Provides shared state management for a group of checkboxes with flex column layout.

| Prop    | Type       | Default | Description                                                    |
| ------- | ---------- | ------- | -------------------------------------------------------------- |
| `value` | `string[]` | `[]`    | Values of the checked checkboxes. Bindable with `bind:value`   |

`CheckboxTree` is also exported as a demo-only helper for the parent checkbox examples (not production-tested).

## Examples

For accessible group labelling and validation, prefer wrapping checkbox groups with `Field` and `Fieldset`. See the related example: [Checkbox group field](/docs/field#checkbox-group-field).
