## Usage

```svelte
<script lang="ts">
  import {
    Stepper, StepperDescription, StepperIndicator, StepperItem,
    StepperSeparator, StepperTitle, StepperTrigger
  } from '#lib/components/ui/stepper';

  let step = $state(1);
</script>

<Stepper bind:step>
  <StepperItem step={1}>
    <StepperTrigger>
      <StepperIndicator />
      <StepperTitle>Account</StepperTitle>
      <StepperDescription>Create your account</StepperDescription>
    </StepperTrigger>
    <StepperSeparator />
  </StepperItem>
</Stepper>
```

## API Reference

### Stepper

| Prop | Type | Default |
| --- | --- | --- |
| `step` | `number` | `1` |
| `orientation` | `'horizontal' | 'vertical'` | `horizontal` |

`step` is bindable.

### StepperItem

| Prop | Type | Default |
| --- | --- | --- |
| `step` | `number` | `auto` |
| `completed` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `loading` | `boolean` | `false` |

Steps before the active one are marked completed. When `step` is omitted it is numbered by order of appearance.

### StepperTrigger, StepperIndicator, StepperTitle, StepperDescription, StepperSeparator

Styled parts. `StepperTrigger` activates its item on click; `StepperIndicator` shows the step number, a check, or a spinner depending on state.
