## Usage

```svelte
<script lang="ts">
  import { AspectRatio } from '#lib/components/ui/aspect-ratio';
</script>

<div class="w-full max-w-sm">
  <AspectRatio ratio={16 / 9}>
    <img alt="Landscape" class="size-full rounded-lg object-cover" src="/photo.jpg" />
  </AspectRatio>
</div>
```

## API Reference

The component renders its own sized wrapper (width 100%, height derived from `ratio`) and absolutely positions its content inside it, so children should fill it (e.g. `size-full`).

### AspectRatio

| Prop | Type | Default |
| --- | --- | --- |
| `ratio` | `number` | `1` |

Also accepts standard `div` attributes.
