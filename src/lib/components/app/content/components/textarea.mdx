## Usage

```svelte
<script lang="ts">
  import { Textarea } from '$lib/components/ui/textarea';

  let value = $state('');
</script>

<Textarea bind:value />
```

## Field Integration

This component wraps the native `<textarea>` in `Field.Control` from ShardsUI internally, so it integrates with `Field` out of the box. There is no need to wrap it in a `FieldControl` manually.

```svelte
<Field>
  <FieldLabel>Bio</FieldLabel>
  <Textarea placeholder="Tell us about yourself…" />
  <FieldDescription>Write a short bio.</FieldDescription>
  <FieldError>This field is required.</FieldError>
</Field>
```

## API Reference

### Textarea

Styled native textarea element with custom size options. `value` and `ref` are bindable; other props are forwarded to `Field.Control`.

| Prop       | Type                                  | Default     | Description                                      |
| ---------- | ------------------------------------- | ----------- | ------------------------------------------------ |
| `size`     | `"sm" \| "default" \| "lg" \| number` | `"default"` | Controls the textarea padding. Number values are passed to the native `rows` attribute |
| `unstyled` | `boolean`                             | `false`     | When true, removes all default styling           |
