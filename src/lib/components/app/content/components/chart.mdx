## Usage

```svelte
<script lang="ts">
  import { BarChart } from 'layerchart';
  import { Chart, ChartTooltip, type ChartConfig } from '#lib/components/ui/chart';

  const data = [
    { month: 'January', desktop: 186 },
    { month: 'February', desktop: 305 }
  ];

  const config = {
    desktop: { label: 'Desktop', color: 'var(--chart-1)' }
  } satisfies ChartConfig;
</script>

<Chart {config} class="h-72 w-full">
  <BarChart {data} x="month" series={[{ key: 'desktop', color: config.desktop.color }]}>
    {#snippet tooltip()}
      <ChartTooltip />
    {/snippet}
  </BarChart>
</Chart>
```

## API Reference

`Chart` wraps [LayerChart](https://layerchart.com) components. It exposes the `config` colors and labels as CSS variables (`--color-<key>`) and provides them to `ChartTooltip`.

### Chart

| Prop | Type | Default |
| --- | --- | --- |
| `config` | `ChartConfig` |  |
| `id` | `string` | `auto` |
| `ref` | `HTMLElement | null` | `null` |

Each `config` entry accepts a `label`, an `icon`, and either a single `color` or a `theme` object (`{ light, dark }`).

### ChartTooltip

A tooltip content component to pass to LayerChart's `tooltip` snippet. It reads labels and colors from the surrounding `Chart` config.

The `getPayloadConfigFromPayload` helper is also exported for building custom tooltips.
