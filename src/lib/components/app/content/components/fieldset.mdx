## Usage

```svelte
<script lang="ts">
  import { Fieldset, FieldsetLegend } from '#lib/components/ui/fieldset';
</script>

<Fieldset>
  <FieldsetLegend>Fieldset legend</FieldsetLegend>
</Fieldset>
```

## API Reference

### Fieldset

Root component. Wrapper for `Fieldset.Root` from ShardsUI.

### FieldsetLegend

Legend for the fieldset. Styled wrapper for `Fieldset.Legend` from ShardsUI with semibold font weight.
