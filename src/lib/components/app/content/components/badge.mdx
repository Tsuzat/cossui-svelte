## Usage

```svelte
<script lang="ts">
  import { Badge } from '#lib/components/ui/badge';
</script>

<Badge>Badge</Badge>
```

## Link

Pass an `href` to render the badge as an anchor (`<a>`) instead of a `<span>`.

```svelte
<script lang="ts">
  import { Badge } from '#lib/components/ui/badge';
</script>

<Badge href="/pricing">New</Badge>
```

## API Reference

This is a custom component, not a ShardsUI wrapper. It renders a `<span>`, or an `<a>` when `href` is set.

### Badge

A badge component with variant and size options.

| Prop      | Type                                                                                                    | Default     | Description                                      |
| --------- | ------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------ |
| `variant` | `"default" \| "destructive" \| "error" \| "info" \| "outline" \| "secondary" \| "success" \| "warning"` | `"default"` | Controls the badge styling and color scheme      |
| `size`    | `"default" \| "sm" \| "lg"`                                                                             | `"default"` | Controls the badge size                          |
| `href`    | `string`                                                                                                | -           | Renders the badge as a link                      |
