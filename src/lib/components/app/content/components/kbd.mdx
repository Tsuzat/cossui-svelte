## Usage

```svelte
<script lang="ts">
  import { Kbd, KbdGroup } from '#lib/components/ui/kbd';
</script>
```

Single key:

```svelte
<Kbd>K</Kbd>
```

Multiple keys (key combination):

```svelte
<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

## API Reference

### Kbd

Displays a single keyboard key.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `class`    | `string` |         |

### KbdGroup

Groups multiple keyboard keys for key combinations.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `class`    | `string` |         |
