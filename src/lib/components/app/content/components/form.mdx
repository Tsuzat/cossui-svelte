## Usage

```svelte
<script lang="ts">
  import { Field, FieldError, FieldLabel } from '$lib/components/ui/field';
  import { Form, type FormErrors } from '$lib/components/ui/form';
  import { Input } from '$lib/components/ui/input';

  let errors = $state<FormErrors>({});
</script>

<Form class="flex w-full flex-col gap-4" {errors}>
  <Field name="email">
    <FieldLabel>Email</FieldLabel>
    <Input name="email" type="email" required />
    <FieldError>Please enter a valid email.</FieldError>
  </Field>
</Form>
```

## API Reference

### Form

Thin wrapper around `Form` from ShardsUI with no default layout. Pass `class` for spacing and structure (for example `flex w-full flex-col gap-4` for a vertical field stack). Accepts the ShardsUI `Form` props, including `errors` (`FormErrors`), `validationMode` (`FormValidationMode`) and `bind:ref`. The unstyled primitive is also exported as `FormPrimitive`.

**Dialog, sheet, drawer:** Place the header **outside** the form. Wrap the panel and footer only in `<Form class="contents">`. The `contents` display value keeps panel and footer participating correctly in the popup flex layout without nesting the header inside the `<form>`.
