## Usage

### Stacked Toasts

```ts
import { toastManager } from '#lib/components/ui/toast';
```

```ts
toastManager.add({
  title: 'Event has been created',
  description: 'Monday, January 3rd at 6:00pm'
});
```

By default, toasts appear in the **bottom-right** corner. You can change this by setting the `position` prop on the `ToastProvider`.

Allowed values: `top-left`, `top-center`, `top-right`, `bottom-left`, `bottom-center`, `bottom-right`. For example:

```svelte
<ToastProvider position="top-center">
  {@render children()}
</ToastProvider>
```

### Deduplicated toasts (upsert)

Pass a stable `id` when calling `toastManager.add`. If a toast with that `id` already exists, ShardsUI updates it in place, refreshes the auto-dismiss timer, and increments `updateKey`. The styled toast replays a short re-notify animation on each update.

```ts
toastManager.add({
  id: 'save-status',
  title: 'Saved',
  description: 'Your draft was updated.'
});
```

### Anchored Toasts

For toasts positioned relative to a specific element, use `anchoredToastManager`. The `AnchoredToastProvider` is typically added to your app layout (alongside `ToastProvider`), so you can use `anchoredToastManager` directly in your components (pass the trigger element, e.g. `event.currentTarget`, as the anchor):

```ts
anchoredToastManager.add({
  title: 'Copied!',
  positionerProps: {
    anchor: buttonElement
  }
});
```

You can also style anchored toasts like tooltips by passing `data: { tooltipStyle: true }`. When using tooltip style, only the `title` is displayed (description and other content are ignored):

```ts
anchoredToastManager.add({
  title: 'Copied!',
  positionerProps: {
    anchor: buttonElement
  },
  data: {
    tooltipStyle: true
  }
});
```

## API Reference

### ToastProvider

Provider component for stacked toasts. Wraps `Toast.Provider` from ShardsUI and renders the stacked toast viewport.

| Prop          | Type                                                                                     | Default          | Description                                                                                            |
| ------------- | ---------------------------------------------------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------ |
| `position`    | `"top-left" \| "top-center" \| "top-right" \| "bottom-left" \| "bottom-center" \| "bottom-right"` | `"bottom-right"` | Position of the toast viewport                                                                         |
| `portalProps` | `ComponentProps<typeof ToastPrimitive.Portal>`                                                                    | -                | Props forwarded to the internal portal (`container`, etc.); see the ShardsUI Toast portal API                |

### AnchoredToastProvider

Provider component for toasts anchored to specific elements. Use with `anchoredToastManager`.

| Prop          | Type                 | Default | Description                                                                             |
| ------------- | -------------------- | ------- | --------------------------------------------------------------------------------------- |
| `portalProps` | `ComponentProps<typeof ToastPrimitive.Portal>` | -       | Props forwarded to the internal portal (`container`, etc.); see the ShardsUI Toast portal API |

### toastManager

Manager object for creating stacked toasts. Use `toastManager.add()` to show a toast. Pass the same `id` on a later `add` to update that toast in place (dedupe) instead of stacking a duplicate.

### anchoredToastManager

Manager object for creating anchored toasts. Use `anchoredToastManager.add()` with `positionerProps.anchor` to show a toast anchored to an element. Repeated `add` calls with the same `id` update in place, same as stacked toasts.

### Toast parts

The viewport, toast root, title, description, action and close button are rendered internally by the providers. The ShardsUI `Toast` primitive is re-exported as `ToastPrimitive` for advanced use, and `toastManager.add()` accepts `title`, `description`, `type`, `timeout`, `actionProps` and `data` (including `rootProps`).
