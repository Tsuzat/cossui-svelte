## Usage

```svelte
<script lang="ts">
  import { PlacesAutocomplete, type SelectedPlace } from '#lib/components/ui/places-autocomplete';

  let place = $state<SelectedPlace | null>(null);
</script>

<PlacesAutocomplete
  apiKey={GOOGLE_MAPS_API_KEY}
  countryCode="us"
  onPlaceSelect={(p) => (place = p)}
/>
```

## API Reference

Requires a Google Maps API key with the Places API enabled. The Google script is loaded on demand. Built on [Autocomplete](/docs/autocomplete).

### PlacesAutocomplete

| Prop | Type | Default |
| --- | --- | --- |
| `apiKey` | `string` |  |
| `onPlaceSelect` | `(place: SelectedPlace) => void` |  |
| `countryCode` | `string | null` |  |
| `value` | `string` |  |
| `defaultValue` | `string` | `''` |
| `onValueChange` | `(value: string) => void` |  |
| `debounceMs` | `number` | `300` |
| `placeholder` | `string` | `'Start typing an address'` |
| `disabled` | `boolean` | `false` |
| `showPoweredByGoogle` | `boolean` | `true` |
| `class / inputClass` | `string` |  |

`SelectedPlace` includes `address`, `placeId`, `lat` and `lng`.
