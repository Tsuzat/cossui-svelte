## Usage

```svelte
<script lang="ts">
  import { Button } from '$lib/components/ui/button';
  import {
    Toolbar,
    ToolbarButton,
    ToolbarGroup,
    ToolbarSeparator
  } from '$lib/components/ui/toolbar';
</script>

<Toolbar>
  <ToolbarGroup>
    <ToolbarButton>Bold</ToolbarButton>
    <ToolbarButton>Underline</ToolbarButton>
  </ToolbarGroup>
  <ToolbarSeparator />
  <ToolbarGroup>
    <Button>Save</Button>
  </ToolbarGroup>
</Toolbar>
```

## API Reference

### Toolbar

Root component. Styled wrapper for `Toolbar.Root` from ShardsUI with flex layout.

### ToolbarGroup

Groups related toolbar items. Styled wrapper for `Toolbar.Group` from ShardsUI.

### ToolbarButton

Button within the toolbar. Styled wrapper for `Toolbar.Button` from ShardsUI.

### ToolbarInput

Input within the toolbar. Styled wrapper for `Toolbar.Input` from ShardsUI.

### ToolbarSeparator

Visual separator between toolbar items. Styled wrapper for `Toolbar.Separator` from ShardsUI.

### ToolbarLink

Link within the toolbar. Styled wrapper for `Toolbar.Link` from ShardsUI.
