## Usage

```svelte
<script lang="ts">
  import { buttonVariants } from '$lib/components/ui/button';
  import {
    Tooltip,
    TooltipPopup,
    TooltipProvider,
    TooltipTrigger
  } from '$lib/components/ui/tooltip';
</script>

<TooltipProvider>
  <Tooltip>
    <TooltipTrigger class={buttonVariants({ variant: 'outline' })}>Hover me</TooltipTrigger>
    <TooltipPopup>Helpful hint</TooltipPopup>
  </Tooltip>
</TooltipProvider>
```

## API Reference

### Tooltip

Root component. Wraps `Tooltip.Root` from ShardsUI. `open` is bindable. Optional `delay` and `closeDelay` props (ms) wrap the tooltip in its own provider.

### TooltipTrigger

Trigger element that shows the tooltip on hover/focus. Styled wrapper for `Tooltip.Trigger` from ShardsUI.

### TooltipPopup

Popup container that displays the tooltip content. Also exported as `TooltipContent`.

| Prop           | Type                                     | Default    | Description                                      |
| -------------- | ---------------------------------------- | ---------- | ------------------------------------------------ |
| `side`         | `"top" \| "bottom" \| "left" \| "right"` | `"top"`    | Side of the trigger to position the tooltip      |
| `align`        | `"start" \| "center" \| "end"`           | `"center"` | Alignment relative to the trigger                |
| `sideOffset`   | `number`                                 | `4`        | Distance from the trigger in pixels              |
| `alignOffset`  | `number`                                 | `0`        | Offset along the alignment axis                  |
| `showArrow`    | `boolean`                                | `false`    | Render an arrow pointing at the trigger          |
| `customAnchor` | `Element`                                | -          | Anchor the popup to an element other than the trigger |
| `portalProps`  | `ComponentProps<typeof TooltipPrimitive.Portal>` | - | Props forwarded to the internal portal (`keepMounted`, `container`, etc.) |

### TooltipProvider

Provider for grouping tooltips. Styled wrapper for `Tooltip.Provider` from ShardsUI.

### TooltipHandle

Alias for `TooltipPrimitive.Handle` from ShardsUI, used to connect detached triggers to a tooltip. `TooltipPrimitive` is also exported.

## Examples

### Grouped Tooltips

To group multiple tooltips so they appear instantly after the first one is opened, wrap them in `TooltipProvider`. The grouping logic ensures that once a tooltip becomes visible, the adjacent tooltips will be shown instantly.

### Shared Tooltips

Bind each trigger's `ref` and pass it to `TooltipPopup` through `customAnchor` to anchor a tooltip to an element other than its own trigger, for example when the trigger is a `ToggleGroupItem`. Control `open` with `bind:open` on `Tooltip`.
