## Usage

```svelte
<script lang="ts">
  import { Label } from '$lib/components/ui/label';
  import { Radio, RadioGroup } from '$lib/components/ui/radio-group';

  let value = $state('next');
</script>

<RadioGroup bind:value>
  <Label><Radio value="next" /> Next.js</Label>
  <Label><Radio value="vite" /> Vite</Label>
  <Label><Radio value="astro" /> Astro</Label>
</RadioGroup>
```

## API Reference

### RadioGroup

Root component. Styled wrapper for `RadioGroup` from ShardsUI with flex column layout. `value` is bindable (`bind:value`); `defaultValue`, `onValueChange`, `disabled`, `name` and the other primitive props are forwarded.

### Radio

Individual radio button. Styled wrapper for `Radio.Root` from ShardsUI with built-in indicator. Takes a `value`. Also exported as `RadioGroupItem`.

The `RadioPrimitive` and `RadioGroupPrimitive` namespaces are re-exported for custom compositions.

## Examples

For accessible labelling and validation, prefer using the `Field` component to wrap radio buttons. See the related example: [Radio Group field](/docs/field#radio-group-field).
