## Usage

```svelte
<script lang="ts">
  import { Skeleton } from '$lib/components/ui/skeleton';

  let loading = $state(true);
</script>

<Skeleton {loading} class="flex items-center gap-4">
  <div class="size-10 rounded-full"></div>
  <div class="h-4 w-40"></div>
</Skeleton>
```

## API Reference

This is a thin wrapper around the `<phantom-ui>` custom element from [`@aejkatappaja/phantom-ui`](https://github.com/Aejkatappaja/phantom-ui), not a ShardsUI wrapper.

### Skeleton

Wraps its children and, while `loading` is true, overlays an animated shimmer that mirrors the layout of the rendered content, so you don't draw skeleton shapes by hand. Children must be rendered (`children` is required); size and shape them with `class`. All `phantom-ui` attributes (`loading`, etc.) are forwarded.
