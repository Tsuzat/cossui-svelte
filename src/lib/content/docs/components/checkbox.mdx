## API Reference

### Checkbox

Styled wrapper for `Checkbox.Root` from ShardsUI. Includes a built-in indicator with checkmark and indeterminate icons.

| Prop            | Type      | Default | Description                                         |
| --------------- | --------- | ------- | --------------------------------------------------- |
| `checked`       | `boolean` | `false` | Checked state. Bindable with `bind:checked`         |
| `indeterminate` | `boolean` | `false` | Shows the indeterminate (mixed) state               |
| `value`         | `string`  | -       | Value used inside a `CheckboxGroup` or form         |
