## API Reference

### StarRating

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number` | `0` |
| `max` | `number` | `5` |
| `allowHalf` | `boolean` | `false` |
| `size` | `'sm' | 'default' | 'lg' | 'xl'` | `default` |
| `disabled` | `boolean` | `false` |
| `readonly` | `boolean` | `false` |
| `label` | `string` | `'Rating'` |
| `name` | `string` |  |
| `icon` | `Snippet<[{ index, state }]>` |  |

`value` is bindable. Passing `name` renders a hidden input for native form submission. `icon` customizes each star; `state` is `'empty' | 'half' | 'full'`.

### StarRatingValue

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number` |  |
| `max` | `number` |  |

Renders the numeric value as text.
