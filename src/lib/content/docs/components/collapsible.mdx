## Usage

```svelte
<script lang="ts">
  import {
    Collapsible,
    CollapsiblePanel,
    CollapsibleTrigger
  } from '$lib/components/ui/collapsible';
</script>

<Collapsible>
  <CollapsibleTrigger>Can I access the file in the cloud?</CollapsibleTrigger>
  <CollapsiblePanel>Yes, you can access the file in the cloud.</CollapsiblePanel>
</Collapsible>
```

## API Reference

### Collapsible

Root component. Wrapper for `Collapsible.Root` from ShardsUI. `open` is bindable (`bind:open`).

### CollapsibleTrigger

Trigger button that toggles the collapsible panel. Wrapper for `Collapsible.Trigger` from ShardsUI.

### CollapsiblePanel

Collapsible content panel. Styled wrapper for `Collapsible.Panel` from ShardsUI with animated height transitions. Also exported as `CollapsibleContent`.
