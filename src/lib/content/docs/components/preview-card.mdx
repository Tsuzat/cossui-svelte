## Usage

```svelte
<script lang="ts">
  import {
    PreviewCard,
    PreviewCardPopup,
    PreviewCardTrigger
  } from '$lib/components/ui/preview-card';
</script>

<PreviewCard>
  <PreviewCardTrigger>Open Preview Card</PreviewCardTrigger>
  <PreviewCardPopup>Preview Card Content</PreviewCardPopup>
</PreviewCard>
```

## API Reference

### PreviewCard

Root component. Wrapper for `PreviewCard.Root` from ShardsUI. Also exported as `HoverCard`.

### PreviewCardTrigger

Trigger element that shows the preview card on hover. Wrapper for `PreviewCard.Trigger` from ShardsUI. Also exported as `HoverCardTrigger`. Use the `child` snippet to render a custom element.

### PreviewCardPopup

Popup container that displays the preview content. Also exported as `HoverCardContent`.

| Prop           | Type                                     | Default    | Description                                      |
| -------------- | ---------------------------------------- | ---------- | ------------------------------------------------ |
| `side`         | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` | Side of the trigger to position the popup        |
| `align`        | `"start" \| "center" \| "end"`           | `"center"` | Alignment relative to the trigger                |
| `sideOffset`   | `number`                                 | `4`        | Distance from the trigger in pixels              |
| `alignOffset`  | `number`                                 | `0`        | Offset along the alignment axis                  |
| `showArrow`    | `boolean`                                | `false`    | Renders an arrow pointing at the anchor          |
| `customAnchor` | `Element`                                | -          | Positions the popup against this element instead of the trigger |
| `portalProps`  | `PreviewCard.Portal` props               | -          | Props forwarded to the internal portal (`keepMounted`, `container`, etc.) |
