## Usage

```svelte
<script lang="ts">
  import {
    Timeline,
    TimelineHeader,
    TimelineIndicator,
    TimelineItem,
    TimelineSeparator,
    TimelineTitle
  } from '$lib/components/ui/timeline';
</script>

<Timeline defaultValue={2}>
  <TimelineItem step={1}>
    <TimelineHeader>
      <TimelineSeparator />
      <TimelineTitle>Project Kickoff</TimelineTitle>
      <TimelineIndicator />
    </TimelineHeader>
  </TimelineItem>
</Timeline>
```

## API Reference

### Timeline

| Prop            | Type                         | Default      |
| --------------- | ---------------------------- | ------------ |
| `defaultValue`  | `number`                     | `1`          |
| `value`         | `number`                     |              |
| `onValueChange` | `(value: number) => void`    |              |
| `orientation`   | `"horizontal" \| "vertical"` | `"vertical"` |

### TimelineItem

| Prop   | Type     | Default |
| ------ | -------- | ------- |
| `step` | `number` |         |

Items whose `step` is less than or equal to the active step are marked completed.

`TimelineHeader`, `TimelineSeparator`, `TimelineIndicator`, `TimelineTitle`, `TimelineDate` and `TimelineContent` are styled wrappers that accept standard element attributes.
