## Usage

```svelte
<script lang="ts">
  import { AspectRatio } from '$lib/components/ui/aspect-ratio';
</script>

<div class="relative w-full max-w-sm">
  <AspectRatio ratio={16 / 9}>
    <img alt="Landscape" class="size-full rounded-lg object-cover" src="/photo.jpg" />
  </AspectRatio>
</div>
```

## API Reference

The component is absolutely positioned: place it in a `relative` container, which is what reserves the space for the ratio.

### AspectRatio

| Prop | Type | Default |
| --- | --- | --- |
| `ratio` | `number` | `1` |
| `ref` | `HTMLDivElement | null` | `null` |

Also accepts standard `div` attributes.
