---
title: IsMobile
description: Reactive flag that is true when the viewport is narrower than the mobile breakpoint.
---

A small class built on Svelte's [`MediaQuery`](https://svelte.dev/docs/svelte/svelte-reactivity#MediaQuery) that matches viewports below `800px`. Read `.current` anywhere reactive, such as a template or `$derived`.

## Installation

## Usage

```svelte
<script lang="ts">
  import { IsMobile } from '$lib/hooks/use-is-mobile.svelte';

  const isMobile = new IsMobile();
</script>

{#if isMobile.current}
  <MobileNav />
{:else}
  <DesktopNav />
{/if}
```

`current` is `false` during SSR. For other queries, use `MediaQuery` from `svelte/reactivity` directly.
